\# Weather App 🌤️



A simple weather application built with Flask and OpenWeatherMap API.



\## Features ✨



\- 🔍 Search weather by city name

\- 🌡️ Display current temperature

\- 💨 Show wind speed and direction

\- 💧 Display humidity level

\- 🔽 Show atmospheric pressure

\- 🎨 Responsive and clean UI

\- 🌍 Real-time weather data from OpenWeatherMap API



\## Tech Stack 🛠️



\- \*\*Backend:\*\* Python Flask

\- \*\*Frontend:\*\* HTML, CSS, JavaScript

\- \*\*API:\*\* OpenWeatherMap API

\- \*\*Database:\*\* JSON file storage



\## Installation 📦



1\. Clone the repository:

```bash

git clone https://github.com/KeerthanaSK7/weather-app.git

cd weather-app

```



2\. Install dependencies:

```bash

pip install -r requirements.txt

```



3\. Create `.env` file and add your API key:

```

OPENWEATHER\_API\_KEY=your\_api\_key\_here

```



4\. Run the app:

```bash

python app.py

```



5\. Open browser and go to: `http://localhost:5000`



\## How to Use 💻



1\. Enter a city name in the search box

2\. Click "Search" button

3\. View current weather information

4\. Search another city or refresh for new data
